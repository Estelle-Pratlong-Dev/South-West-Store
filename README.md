# South-West-Store

Site e-commerce consacré à la vente de sneakers de collection.

> Projet de fin de formation — 2019, poursuivi et enrichi personnellement après l'obtention de mon diplôme.

## Le projet

South-West-Store a été initialement développé en groupe dans le cadre de mon projet de fin de formation de Développeuse Web et Web Mobile.

Après la formation, j'ai continué à faire évoluer personnellement le projet afin d'ajouter de nouvelles fonctionnalités et d'approfondir ma pratique de Symfony.

Le projet couvre les principales fonctionnalités d'un site e-commerce, de la consultation du catalogue jusqu'à la gestion des commandes et du back-office.

## Fonctionnalités

- Catalogue de produits
- Recherche et filtres avancés
- Fiches produits
- Création et gestion des comptes clients
- Authentification
- Réinitialisation du mot de passe
- Suppression du compte utilisateur
- Gestion du panier et des commandes
- Gestion du stock
- Back-office d'administration

## Stack technique

- PHP
- Symfony
- Twig
- MySQL
- JavaScript
- Bootstrap
- Git
